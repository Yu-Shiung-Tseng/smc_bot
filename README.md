# 🚀 SMC 多時區量化交易機器人 (SMC MTF Trading Bot)

這是一個專為加密貨幣（目前以 ETH/USDT 為主）設計的自動化量化交易專案。
本專案採用機構級別的 **聰明錢概念 (Smart Money Concepts, SMC)**，結合嚴格的 **多時區共振 (Multi-Timeframe, MTF)** 邏輯，並具備無未來資料污染 (Look-ahead bias free) 的本地回測引擎。

---

## 🎯 專案目標與核心策略

本機器人不依賴傳統的 MA/RSI 等落後指標，而是透過尋找市場上的「流動性失衡」與「訂單塊」來跟隨主力資金進出場。

### 核心交易邏輯 (多時區共振)
1. **大局觀 (4H 級別)：** 尋找大時區的資金缺口 (FVG)，確立目前的宏觀趨勢（看多或看空）。
2. **狙擊區間 (1H 級別)：** 順著 4H 的趨勢，在 1H 圖表上尋找同方向的 FVG 作為「潛在進場區間」，並利用最近的訂單塊 (Order Block, OB) 作為結構防守止損點。
3. **精準觸發 (5m 級別)：** 不盲目掛單。必須等到 5 分鐘 K 線確實「回踩」進入 1H FVG 區間，且收盤價沒有突破不利邊界時，才正式觸發進場訊號。

## 📂 專案架構與模組說明

專案採用高度解耦的模組化設計：

* `data/`：(已被 Git 忽略) 存放從 Binance 下載的本地 CSV 歷史 K 線數據。
* `market_data/`：負責與 Binance API 溝通，具備斷點續傳、自動補缺口、防未來資料的下載器，並將數據標準化存入本地 CSV。
* `indicators/`：完全自研的 SMC 指標運算核心。嚴格區分指標的「發生時間 (source_at)」與「確認可用時間 (confirmed_at)」，杜絕回測時的未來資料污染。
* `strategy/`：多時區策略大腦。負責對齊 4H、1H、5m 的數據，判斷是否滿足進場條件，並產出標準化的「交易計畫 (TradePlan)」。
* `risk/`：風控與倉位管理。根據設定的風險承受度 (例如單筆虧損不超過本金 2%) 與止損距離，動態計算下單數量 (Coin) 與所需保證金。
* `tests/`：單元測試模組，確保策略與指標邏輯的絕對正確。
* `run_backtest.py`：時光機回測引擎。能步進模擬歷史盤勢，產出勝率與損益報告。

## 🔥 下一步開發計畫 (Next Steps)

1. **效能極限優化 (High Priority)：**
   - **問題：** 目前回測引擎在每一個 5 分鐘的決策點，都會從頭計算數千根 K 線的 SMC 指標，導致時間複雜度呈 $O(N^2)$，跑兩週數據需耗時 10 分鐘以上。
   - **解法：** 導入「增量計算 (Incremental Calculation)」或「指標快取 (Cache)」，讓策略只計算最新一根 K 線的變化，大幅縮短回測與實盤運算時間。
2. **BingX API 實盤串接：**
   - 將策略產出的交易計畫，轉換為 BingX V2 API 的開倉、掛止損單、掛移動止盈單指令。
3. **狀態管理模組 (State Management)：**
   - 建立本地資料庫或 JSON 狀態檔，記憶機器人當前的「持倉狀態」，避免在同一個 FVG 區間內重複觸發開單。
4. **自動化排程器 (Scheduler)：**
   - 部署持續運行的常駐程式，每 5 分鐘自動喚醒抓取數據並執行策略決策。
